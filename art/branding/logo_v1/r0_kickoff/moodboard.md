## Tesis del moodboard

> **SONAR es un instrumento que ve escuchando — metáfora abstracta de profundidad.** El logo debe transmitir cinco cualidades en orden de prioridad descendente: **(1) profundidad simbólica**, **(2) precisión técnica**, **(3) calma autoridad**, **(4) atemporal 5+ años**, **(5) bioluminescent identity firma marketing FiveM**.
>
> El moodboard converge hacia logomarks geométricos minimalistas tipo **Linear/Vercel/Stripe** (precisión + tech confidence + dark+light parity) **estructuralmente cruzados** con vocabulario visual de **profundidad abstracta no-literal** (geological strata, topographic curves, architectural sections, oceanographic depth profiles, layer stacks) — **divergiendo radicalmente** de cualquier referencia submarino-militar, sonar-ping radio/freq, anchor/wheel marítimo, cyberpunk neón, gaming RGB, cartoon mascot.

**Aprendizajes formales convergentes:**

- **Cero literalismo submarino:** ningún periscopio, ninguna silueta sub, ningún torpedo. La profundidad es **simbólica geométrica**, no pictórica.

## Columna 3 — ✅ Hybrid theme (dark+white parity — ADR-012 D2)

> **Requirement crítico v2:** SONAR usa hybrid theme (~30-40% dark + ~30-40% white surfaces). El logo debe funcionar primario en **ambos canvases con paridad visual** (brief §2.2). Estos refs muestran cómo logomarks contemporáneos resuelven esta dualidad.

| # | Caso | URL referencia | Lección hybrid theme |
|---|---|---|---|
| H1 | **Notion** dark sidebar + white workspace | https://notion.so | Logo Notion funciona idéntico en ambos canvases — color identity preservado, geometry intacta. |
| H2 | **Stripe Dashboard** dark sidebar + white content | https://stripe.com/docs | Logo Stripe en sidebar dark + en docs white = paridad confianza. |
| H3 | **Arc Browser** dark chrome + light content | https://arc.net | Color firma identity (peach Arc) preserva intensidad ambos themes. |
| H4 | **Linear** dark canvas + white modal | https://linear.app | Logo Linear violet brilla AAA dark + AA+ light sin shift. |
| H5 | **GitHub** dark mode mixed surfaces | https://github.com (dark mode) | Octocat funciona dark + light — silueta recognizable independiente del canvas. |
| H6 | **Vercel** docs dark + light parity nativa | https://vercel.com/docs | Triangle Vercel = canonical dark+light parity case study. |

**Aprendizajes hybrid theme convergentes:**
- Color identity **preservado en ambos canvases** (sin invertir a complementario).
- Si contraste falla en white canvas, **shift sutil de tono** (e.g., `#2DD4BF` → `#1FB39E` bridge AA) — **no** cambio dramático identity.
- **Border 1px contraste-forzado** opcional para edge cases white surface (brief §2.2 menciona esta opción).
- **Glow/halo siempre opcional decorative**, jamás soporte de legibilidad.

## Columna 4 — ❌ Anti-references (hacer lo OPUESTO — explicit purga ADR-012)

> **Estos son los anti-patrones absolutos.** Si un draft R1 toca cualquiera de estas familias visuales → descartar inmediatamente sin defenderlo. El brief y ADR-012 D1 son explícitos: SONAR es metáfora abstracta, NO submarino militar, NO sonar-ping radio, NO gaming neón.

| # | Anti-categoría | Ejemplo emblemático | Por qué prohibido |
|---|---|---|---|
| A1 | **Sonar ping concentric waves** | Cualquier logo radar/sonar industrial con 3-4 ondas concéntricas | **Explicit purga ADR-012 D1.** Es radio/freq literal, NO profundidad simbólica. v1 brief locked en esto y fue descartado. |
| A2 | **Submarino silhouette literal** | Logos de tour operators submarino, naval defense | Submarino militar literal = anti-canónico ADR-012 D1. |
| A3 | **Periscope/hydrophone/torpedo iconography** | Naval defense brand identities | Equipo submarino literal. Purgado por ADR-012. |
| A4 | **Anchor/wheel marítimo** | Cualquier logo nautical heritage Admirals-style | Heritage v1.0 Admirals deprecated por ADR-011. NO retornar. |
| A5 | **Acoustic waveform / oscilloscope** | Logos audio production, podcast, music apps con onda visible | Es hardware acústico, NO metáfora abstracta. |
| A6 | **Compass / navigation symbols literales** | Cualquier brújula minimalist | Es navigation literal, NO profundidad simbólica. |
| A7 | **"Eye that sees" eye-with-rays** | Logos surveillance, all-seeing-eye | Literal "ver escuchando" = banal + connotación surveillance hostile. |
| A8 | **Cyberpunk neón saturado** | Cyberpunk 2077, Razer, futuristic gaming brands | Trend 2020s desactualiza. SONAR es atemporal. |
| A9 | **Military tacticool** | CoD, Rainbow Six, Call of Duty Tactical | Anti-canónico voz neutral premium-tech. |
| A10 | **Gaming RGB rainbow** | Razer, MSI, Alienware, Corsair | Gamer chillón, opuesto a calma autoridad. |
| A11 | **Cartoon mascot** | Twitch chibi mascots, server RP memes | SONAR es premium-tech infrastructure, no Notion-playful o gaming-mascot. |
| A12 | **Vintage/retro motivational** | "Adventure begins" badge style, motivational corp | Trend 2010s desactualiza, opuesto a atemporal moderno. |
| A13 | **Bevel / drop-shadow / emboss** | Logos Web 2.0 era 2005-2010 | Anti-pattern misuse documented brief §5.2. |
| A14 | **Gradient holográfico mercurio rainbow** | Instagram 2016 logo, holographic NFT branding | Anti-pattern color rule brief §3.4. |

**Aprendizajes anti-convergentes:**
- Si la silueta del logo SONAR sugiere **una cosa concreta** (un objeto, un hardware, una herramienta), está mal. Debe sugerir **una cualidad abstracta** (profundidad, capas, descenso).
- Si el logo funciona solo a 256px+ pero falla a 16px favicon, está mal. **Test favicon = constraint primario.**
- Si el logo necesita color para ser identificable, está mal. **Silueta B&W = test forma.**
