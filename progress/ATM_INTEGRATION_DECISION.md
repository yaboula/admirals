# ATM Integration Decision — C031

## Decision

C031 `sonar:bank:atm:withdraw` is restricted to physical in-game ATM terminals.

The NUI bank app must not expose a production withdrawal execution button. Any real `signature_hex` for the HMAC-signed withdraw payload must be generated by the client Lua ATM hardware/in-game terminal integration, not by the web app.

## Implementation impact

- No production NUI mutation button for ATM withdraw in `sonar_bank_app/web-src`.
- No web-only generation or storage of ATM HMAC material.
- Future ATM terminal work should implement the signer in client Lua and submit the signed payload to the existing C031 backend callback.
